Basic Web Architecture & Databases

Let's say you have a mobile app and a website. You have a single server which also takes care of the database, web cache, and business logic.

First, when the user clicks the link, the user's website/mobile app sends a request to the DNS to fetch the IP address of the website server.The DNS is a 3rd party which will lookup the domain name and send back the ip address

Now the user's device sends an HTTP (HyperText Transfer Protocol) request to the server as it knows the ip address now, which then sends back the requested HTTP/JSON data.

The frontend (client side) uses HTML, JS languages, whereas the backend (server side) uses Java, Python, C#, etc.

Now let's say we want to separate the database from the existing server and make it into two.

Now everything is the same except the server also interacts with the database.

The types of databases are relational databases (also called RDBMS / SQL databases), which are tables with rows and columns.
Examples: MySQL, Oracle DB, PostgreSQL DB.

Another type is non-relational databases (also called NoSQL databases). There are 4 types — key-value, graph nodes, column stores, and document stores.
Examples: Cassandra, Amazon DynamoDB, etc.
